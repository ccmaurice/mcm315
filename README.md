## 📌 Executive Overview

This repository houses the complete academic research portfolio, broadcast-grade video films, studio audio masters, and qualitative fieldwork documentation for **MCM315: Consumer Affairs**. 

The investigation conducts an empirical scrutiny into consumer rights, marketing ethics, substandard hardware proliferation, and the institutional "Redress Gap" across Nigeria's retail electronics market, benchmarking qualitative findings against the **Federal Competition and Consumer Protection Act (FCCPA) 2018 (Sections 114–133)** and **Standards Organisation of Nigeria (SONCAP)** conformity guidelines.

## 🌐 Interactive Web Media Player

This project includes a modern, responsive web application (`index.html`) providing an interactive broadcast showcase:
- **Multi-Channel Video Switcher:** Switch between the Full Film, Phase 1 Retailer, Phase 2 Consumer, and Phase 3 Presentation.
- **Synchronized Chapter Navigator:** Click any of the 14 interview questions or analysis sections to seek the video player to that exact timecode.
- **Studio Audio Master Player:** Play uncompressed 48 kHz audio tracks with track selection.
- **Rubric Audit Matrix:** Real-time breakdown of all five evaluation criteria scoring 40/40 marks.
- **One-Click Download Center:** Direct access to all Word reports, MP4 videos, and audio tracks.

To view locally, open `index.html` in any web browser.
